# ✨ Web Novel Parser ✨

Web小説向けのパーサーです！🚀

このパーサーは、様々なWeb小説の記法をHTMLに変換することができます。 
これにより、Web小説をより多くのプラットフォームで、より快適に記述することができるようになります。 
Web小説のフォーマットをHTMLに変換することで、様々なデバイスやプラットフォームで読めるようになり、アクセシビリティが向上します。

## 🎉 特徴

**様々な記法に対応！**  
一般的なWeb小説の記法に対応しています。 

    - なろう
    - カクヨム

他、今後対応する小説を増やす予定です。
  
**HTMLに変換！**  
HTMLに変換することで、様々なプラットフォームで表示することができます。

## Tawriとの連携

このパーサーは、[Tawri](https://github.com/L4Ph/Tawri)と連携して動作します。  
Tawriは、Web小説の執筆に特化したエディタで、このパーサーを用いることで、様々な記法で書かれたWeb小説をHTMLに変換し、リアルタイムなプレビューと変換を実現しています。
